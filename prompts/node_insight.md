# 节点解释提示词

请根据当前客户分析上下文，为指定本体节点生成解释。

## 输入

- 当前节点：`{{active_step}}`
- 客户信息：`{{customer}}`
- 资金需求：`{{fund_needs}}`
- 结算场景：`{{scenarios}}`
- 产品组合：`{{product_bundles}}`
- 使用诊断：`{{coverage}}`
- 价值结果：`{{value_result}}`

## 输出要求

请输出一段适合展示在驾驶舱右侧卡片里的文本，包含：

1. 该节点被点亮的业务含义。
2. 当前判断的关键依据。
3. 客户经理下一步应该做什么。

控制在 120 字以内。
