# 客户拜访纪要解析提示词

请从客户经理拜访纪要或录音转写文本中提取结算业务线索。

## 输入

- 客户信息：`{{customer}}`
- 拜访纪要/录音转写：`{{visit_text}}`
- 已有流水分析结果：`{{analysis_context}}`

## 输出要求

提炼一项最明确、最值得进入经营画布的新增资金需求，并在独立字段中判断它可能发生的结算场景。输出必须能够区分“客户原话证据”“资金需求结论”和“场景判断”，不得虚构金额、账户数量或产品使用状态。

资金需求只回答“客户需要解决什么资金问题”，不得混入场景名称、产品名称或产品方案；结算场景只回答“该资金需求发生在哪类经营活动中”。

当调用方要求 JSON 时，严格返回以下字段：

- `needType`：凝练后的资金需求。
- `scenarioName`：可落到结算业务链路中的场景名称。
- `confidence`：0 到 1 的置信度。
- `summary`：只描述资金需求的业务结论，不包含结算场景和产品推荐。
- `evidenceQuote`：直接摘取的一段客户原话。
- `rationale`：为什么原话支持该需求。
- `scenarioRationale`：为什么该资金需求可映射到所选结算场景，不包含产品推荐。
- `nextQuestion`：下一步核实问题。
- `recommendedProducts`：可进一步评估的产品名称数组。

如果文本证据不足，降低置信度，并在 `summary` 与 `nextQuestion` 中明确“待核实”。
